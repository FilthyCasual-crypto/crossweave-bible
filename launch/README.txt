CROSSWEAVE - offline copy

No install needed beyond Python 3 (python.org). Nothing is sent anywhere; it runs on your machine.

  Windows:        double-click start.bat
  macOS / Linux:  open a terminal in this folder and run   sh start.sh

Your browser opens http://localhost:8017/. Close the terminal window to stop.

Do not open app/index.html directly - browsers block the data files over file://.

Prefer not to download anything? The same app is online:
